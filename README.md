# Riverside Family Health – appointment requests + reception desk (demo)

WordPress demo for a **fictional** family clinic: patients request an appointment (only doctors who offer the chosen service, only real free times), reception confirms / declines / reschedules / cancels with conflict-safe confirmation, test-only notifications and secure patient links. No paid plugins.

- `plugin/riverside-booking/` – the booking plugin
- `theme/riverside-health/` – the site theme (v1.1.0)
- `staging/` – staging-only test helper (never deploy to production)
- `tests/acceptance.mjs` – Playwright acceptance tests (13 checks)
- `PLAN.md`, `TEST-REPORT.md`, `CLAUDE.md` / `AGENTS.md` – plan, results, full project context

Built by Mouzzam Channa. All names, doctors, patients, phone numbers and emails are fictional.
