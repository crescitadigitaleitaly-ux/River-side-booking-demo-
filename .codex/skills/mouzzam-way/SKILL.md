# Mouzzam's way of working (repo copy, works in Codex Cloud)

**Who:** Mouzzam Channa, independent web developer (business: Crescita Digitale Italia), selling on Upwork and Fiverr. Goal: win paid jobs with honest, professional, measured portfolio work. He is not very technical: decide technical details like a senior developer and ask him only what only he can do (logins, approvals, payments, creating a GitHub repo, tokens).

**First read:** this repo's `AGENTS.md` (identical to `CLAUDE.md`). If you are on his laptop (Local), also read `C:\Users\MouzzamChanna\Desktop\projects\memory.md` and `C:\Users\MouzzamChanna\Desktop\projects\codex-onboarding\README.md`. In Cloud those files do not exist; the full guide is in the private hub repo `crescitadigitaleitaly-ux/-private-repo-live-websites`, folder `codex-onboarding/`.

## Rules
1. **Plan + OK only for changes.** Building, editing, installing, deploying, anything on a live site or spending credits: short plan first, then wait for his OK. Read-only checks, questions and the next small step of an approved plan: just do them and report.
2. **Staging before live.** Never change a production website without his explicit yes for that change and a backup first.
3. **Honesty.** Never invent results, clients or scores. Demo businesses are fictional and labelled; test data is test data.
4. **No secrets in files.** Never write passwords, tokens or keys into anything committed.
5. **Storage.** Code, `AGENTS.md`, `CLAUDE.md`, `PLAN.md`, reports → GitHub (commit small, push every session). Screenshots, videos, recordings → the project's Google Drive folder (subfolders 01 Evidence originals, 02 Evidence blurred, 03 Test reports, 04 Video recordings, 05 Video final, 06 Portfolio). Never commit videos or raw recordings.
6. **Leave a trail.** After work: update `AGENTS.md` and `CLAUDE.md` (status, done, left, not verified), commit, push.
7. **Platform content rules.** Public images/videos follow Upwork and Fiverr rules: blur emails, phones (even fake), WhatsApp and URLs; no platform names in videos; call to action "send me a message"; never show "Crescita Digitale Italia" in Fiverr material.
8. **Language.** Short, simple English. If he writes in Urdu/Hindi, reply in Roman Urdu (Latin letters).

**Demo projects** (most projects): zero cost (free tools, plugins, tiers only), real integrations in sandbox/test mode (payments in test mode or clearly simulated, emails to a test outbox), client-grade output, honest demo labels.

## What Cloud can and cannot do
- **Can:** write and fix code in this repo, run tests, open pull requests.
- **Cannot:** reach his Hostinger account, WordPress sites (Novamira) or Google Drive; those logins live only on his laptop. Leave a clear note in `AGENTS.md` ("needs Local Codex or Claude: deploy / Drive upload") instead of trying.
